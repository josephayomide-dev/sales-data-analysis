
# Sales Data Analysis with Python

## Project Overview
This project analyses an illustrative retail sales dataset using Python. The goal is to understand product performance, compare revenue, and examine monthly sales trends.

## Tools and Libraries
- Python
- Pandas
- Matplotlib

## Analysis Performed
- Created a dataset containing dates, products, quantities sold, and unit prices.
- Calculated revenue for each transaction.
- Compared total units sold by product.
- Analysed total and average transaction revenue by product.
- Examined monthly revenue trends.
- Created bar and line charts to visualise the findings.

## Key Findings
- Total revenue across 12 transactions was 525,000.
- Rice was the best-selling product, with 110 units sold.
- Rice generated the highest total revenue at 220,000.
- Cooking Oil generated 192,500 in revenue.
- Monthly revenue increased from 97,500 in January to 166,000 in April.

## Business Insights
- Monitor Rice inventory because it leads in units sold and revenue.
- Track Cooking Oil because it contributes substantially to total revenue.
- Continue monitoring monthly sales to see whether the upward trend persists.

## Limitations
The dataset is illustrative and contains only 12 transactions. Revenue is not profit because product costs and other expenses are not included.

## How to Run
Open the `sales-data-analysis.ipynb` notebook in Google Colab or Jupyter Notebook and run the cells in order.
